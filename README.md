# Flicks on AppLovin

Concept demo by Flam. A small puzzle game, Bloom Sort, with a Flick in every AppLovin placement that can run one: interstitial (Cadillac), MREC (Ben & Jerry's), portrait Flick in the rewarded slot (Zara), product catalog (Coach, Levi's, Gap, Patagonia) and playable (Airbnb).

Not an AppLovin product.
