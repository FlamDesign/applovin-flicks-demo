# Flicks on AppLovin

Concept demo by Flam. A small puzzle game, Bloom Sort, with every AppLovin ad placement a player meets in one session: app open, banner, the 3-part interstitial (video, interactive page, catalog), MREC, rewarded video, native, playable, and a DSP video with an end card.

Each ad can be shown as it runs on AppLovin today or with a Flick. Not an AppLovin product.

Open `index.html` or the GitHub Pages link.
